# Quick Answer: Where to Test Integrations

## 🎯 UI Location

**`/dashboard/integrations`**

- **Local**: `http://localhost:3000/dashboard/integrations`
- **Production**: `https://huzaifaiftikhar.engineer/dashboard/integrations`

## ✅ What You Can Do

1. **View Integrations** - See all Calendar, CRM, and Webhook integrations
2. **Test Connection** - Click "Test" button on any integration
3. **Enable/Disable** - Toggle integration on/off
4. **Create New** - Add Google Calendar, CRM, etc.

## 📋 Tabs

- **Calendar Tab** - Google Calendar, GoHighLevel, Calendly, Zocdoc
- **CRM Tab** - Salesforce, HubSpot, Zendesk, Freshdesk
- **Webhooks Tab** - Webhook endpoints
