It can send SMS reminders. It can send email reminders. It can check insurance eligibility. It can answer questions about hours and services.

Medical Assistant can handle medication refill requests. It can explain lab test results. It can collect pre visit intake information. It can send prep instructions for tests. It can connect to EMR systems for medication history. It can connect to lab systems for results.

Triage Nurse Assistant can check patient symptoms. It can score symptom severity from one to ten. It can detect red flag symptoms. It can call emergency services for critical cases. It can connect to provider schedules. It can save notes to patient medical records.

Billing Specialist can explain patient bills. It can answer insurance questions. It can process payments securely. It can generate payment receipts. It can connect to billing systems.

Collections Specialist can send automatic payment reminders. It can collect payments securely. It can set up payment plans. It can follow calling rules and regulations. It can manage overdue balances.
